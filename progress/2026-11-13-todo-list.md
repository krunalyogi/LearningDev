# Todo List Application

**Date:** November 13, 2026  
**Category:** JavaScript Project

## What I Built
- Created a Todo List application using HTML, CSS and JavaScript.
- Implemented adding and deleting tasks.
- Added localStorage persistence.

## Concepts Practised
- DOM manipulation
- `document.createElement()`
- Arrays and objects
- Functions, parameters and closures
- `findIndex()` and `splice()`
- `JSON.stringify()` and `JSON.parse()`
- localStorage

## Challenges Faced
- Understanding how dynamically created elements are added to the DOM.
- Passing element references and IDs between functions.
- Making each Delete button target the correct task.
- Understanding how localStorage stores and retrieves data.

## Key Takeaways
- JavaScript can dynamically create and remove HTML elements.
- Closures help event handlers retain access to their surrounding variables.
- localStorage stores strings, so objects and arrays need JSON serialization.
